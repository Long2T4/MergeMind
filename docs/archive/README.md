# Archived Plans

This folder keeps approved stage plans after their stage is complete, when the team wants the plan kept for reference instead of deleted.

- **Filename:** the same as in `docs/plans/`, for example `stage-10-plan.md`.
- **When:** after the stage's last PR merges. Use `git mv` so the file's history is kept.
- **Contents:** the plan as approved, with its checkboxes closed and a one-line "Archived" note at the top. Archived plans aren't updated after that.

Current status always lives in [docs/PROJECT_PLAN.md](../PROJECT_PLAN.md), not here.
